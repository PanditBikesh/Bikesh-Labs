# Bikesh Labs

Personal portfolio website of Bikesh Kumar Pandit.

**Live Website:** https://bikeshpandit.com.np

## About

Bikesh Labs is a personal portfolio website showcasing engineering interests, technical skills, and software development projects.

## Technology Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- React Router 7
- React Helmet Async
- React Hook Form
- Zod
- Lucide React
- React Icons

## Features

- Responsive portfolio website
- Dark and light themes
- Persistent theme preference
- Multi-page navigation
- SEO metadata and sitemap
- Projects and skills sections
- Contact and resume pages
- Vercel deployment

## Installation

Clone the repository:

    git clone https://github.com/PanditBikesh/Bikesh-Labs.git

Navigate to the application:

    cd Bikesh-Labs/apps/web

Install dependencies:

    npm install

## Development

    npm run dev

## Production Build

    npm run build

## Preview

    npm run preview

## Lint

    npm run lint
